==== Modeling system agents for Lost and Found
:author: Naedra Feliciano
===== 1. Identifiying Relevant System Agents:
Human Agents: 

- Students and Faculty (UPRM) : Report lost/ found items
- Admins : review repots and manage them in case of misuse or abuse

System(Software) Agents:

- Notification Agent : Sends alerts and messages
- Manage Repors (Lost or Found) Agent 
- Athentitication agent : Handles login and signup
(There's more, but for now, let's just focus on this ones)


===== 2. Clasify each identified agent (environmental or Software):

- Human agents  are *environmental agents*:
- System agents are *Software-to-be- agents*
