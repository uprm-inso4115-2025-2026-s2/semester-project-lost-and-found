==== *Synopsis*
The Lost and Found project is meant to help students and faculty at the University of Puerto Rico Mayagüez recover misplaced items with less guesswork and less running around campus. The main problem is not that a digital tool is missing. It is that the current process is unclear and scattered, so people do not know where to start, what information matters, or whether an item is still worth checking for.

For this milestone work, we will keep refining the domain description using concrete observations and stakeholder input, then turn that into traceable requirements and a small set of end to end features. We will also document the design decisions that affect privacy and trust, and we will validate and verify the main flows using realistic scenarios and acceptance checks.

The scope stays campus focused. The platform supports reporting and discovery, helps people coordinate recovery, and aims to reduce unnecessary exposure of personal details. It does not manage the physical storage of items and it does not extend beyond the UPRM campus.
