== I. User Access & Authentication

[discrete]
=== 1. Authenticate with UPR

*Event / Trigger:
*User attempts to log in using their official UPR.edu account. +
*System Behavior:
*System validates credentials through UPR authentication integration and creates an authenticated session. +
*Inputs:*

* upr_email: str
* upr_token: str
*Output:*

* AuthSession
*Function Signature:*
def authenticate_with_upr(upr_email: str, upr_token: str) -> AuthSession
[discrete]
=== 2. Authorize User Action

*Event / Trigger:

*System Behavior:
*System verifies whether the user role permits the requested action. +
*Inputs:*

* user_id: str
* action: str
*Output:*

* bool
*Function Signature:*
def authorize_user_action(user_id: str, action: str) -> bool
