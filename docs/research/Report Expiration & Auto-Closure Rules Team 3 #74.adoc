= [Research] Report Expiration & Auto-Closure Rules (Team 3)

= Goal
Automatically manage stale or inactive reports.

= Description
Define rules for automatic report expiration (ex: 30 days of inactivity).
Specify how the system updates report state, sends warnings, and moves expired reports to an archive.

This is a research/specification task (no coding).

= Proposed Rules:
* Reports expire after X days of inactivity (default: 30 days).
* Inactivity = no edits or status updates.
* System automatically changes state from ACTIVE → EXPIRED.
* User receives warning notification before expiration (ex: 3 days prior).
* Expired reports move to Archive and are not shown in default search.
* Users can manually reactivate expired reports (rules defined by team).

= Acceptance Criteria
* Expiration timeframe is configurable.
* System auto-updates state after expiration.
* User is warned before expiration.
* Expired reports only visible in Archive.
* Manual reactivation rules are clearly defined.
