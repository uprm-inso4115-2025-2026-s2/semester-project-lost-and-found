= Research: Public Transparency Log (Profile Audit Trail)
Author: Diego A Rios Morales
Date: February 26, 2026

== Goal
Add a public "Transparency Log" to user profiles that shows a chronological history of public actions to increase accountability and trust.

== Design rules 
* Default sort: Newest to Oldest
* Each entry shows: Action,Time,Object title/type and Link (if still public)
* Filters: All / Reports / Confirmations / Verification-Roles

== Public vs Private actions

=== Public (OK to show)
* Report submitted
* Report updated (show “edited” + safe field names only not raw old content)
* Report confirmed (prefer countsover naming confirmers)
* Report resolved/closed
* Verification granted/removed
* Role granted/removed (Trusted Reporter, Moderator, etc.)

=== Private (Never show)
* Login/device/IP/security events
* Email/phone/password changes
* Private report categories 
* Internal moderation notes and internal reason codes
* Full edit diffs or deleted content
