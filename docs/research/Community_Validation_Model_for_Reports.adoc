= Community Validation Model for Reports
Author: Diego A Rios Morales
Date: February 26, 2026

== Goal
Explore how LOST AND FOUND users can participate in confirming report accuracy while maintaining credibility and preventing misuse.

== What “validation” means on LOST & FOUND
Users are not confirming ownership. They are confirming *observable details* such as:
* sighting/location accuracy
* turned-in confirmation 
* duplicate/resolved status 
Users should *not* validate: “this belongs to X.”

== Proposed Solution
Add two structured actions on each post:
* *Confirm* (I can verify this is accurate)
* *Flag* (this seems wrong/suspicious)

== Abuse Prevention (simple rules)
* One action per user per post + rate limits
* Weight validation internally using trust signals (account age + verified status)
* If a post gets flagged a lot → switch to “Under Review” and request more evidence (better photo/details)

== Wireframe (what to draw)
On each post card:
* Status badge near the title
* Buttons: Confirm | Flag
* Link: “Why this status?” → small panel explaining the badge in 1 sentence
