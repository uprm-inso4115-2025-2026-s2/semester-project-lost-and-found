= Research: Trust-Focused User Profile Structure (Transparency + Privacy)
Author: Diego A Rios Morales
Date: February 26, 2026

== Goal
Define how user profiles should be structured to maximize trust, transparency, and clarity while protecting user privacy.

== Proposed Solution
Design a clean, trust-focused profile that prioritizes credibility indicators at the top (Verified badge, Member since date, Activity summary) while keeping sensitive information private by default.

== Design rules
* Transparency-first layout: trust indicators appear above bio/content
* Minimal clutter: show only what helps users assess credibility quickly
* Clear public vs private separation: no “grey area” fields
* Consistent labels and icons for trust signals (Verified, Member since, Reports, Confirmations)

== Public vs Private information

=== Public (OK to show)
* Display name + @handle
* Verified badge (if applicable) + what it means (tooltip)
* Member since (account creation month/year)
* Activity summary (counts): reports submitted, confirmations, accuracy rate (if supported)
* Reputation/trust status (e.g., Trusted Reporter) if your system uses roles
* Public contributions list (recent public reports / confirmations)

=== Private (Never show)
* Email, phone number, exact address, precise location history
* Login/device/IP/security details
* Government ID / verification documents
* Private reports or sensitive categories
* Hidden moderation notes, internal flags, or enforcement reasons
