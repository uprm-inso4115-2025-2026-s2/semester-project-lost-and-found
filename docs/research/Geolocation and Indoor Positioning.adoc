= Geolocation and Indoor Positioning Research
Author: Jose Valentin
Date: February 15, 2026

== Recommended Solution: Manual Location Selection

=== Why Manual Selection
* Zero cost 
* Works on web and mobile
* Most reliable - users know where they lost/found items
* No privacy concerns
* Simple to implement
* No hardware or infrastructure needed

=== How It Works
User selects location from predefined campus options:

. Building name (dropdown)
. Floor/Area (dropdown)

== Indoor Positioning Alternatives (Not Recommended)

=== GPS
*Accuracy:* 10-20m outdoors, poor indoors

*Issues:*

* Doesn't work inside buildings
* Battery drain
* Privacy concerns

=== Wi-Fi Triangulation
*Accuracy:* 5-15m

*Issues:*

* Requires complex setup and fingerprinting
* High implementation complexity
* Not worth it for class project scope

=== Bluetooth Beacons
*Accuracy:* 1-3m

*Issues:*

* Costs $1,000+ for campus coverage
* Requires physical installation

=== QR Code Tags
*Accuracy:* Exact location

*Pros:* Cheap (~$25 for 50 codes)

*Cons:* Requires printing and posting around campus

== Recommended Precision Level

*Building + Floor is sufficient:*

* "Lost in Library - 2nd Floor"
* "Found near Student Center entrance"

*Room level precision:* Optional but not necessary

== Implementation Approach

=== Location Selector
* Dropdown menu for building selection
* Dropdown menu for floor/area selection
* Text field for additional details

=== Data Storage
* Create locations table in Supabase with predefined campus buildings
* Link items to location entries
* Store optional text description with each item

=== Search Functionality
* Allow users to filter items by building
* Filter by floor within building
* Search by text description

== Privacy Approach

*Store:*

* Building/floor selection (user chosen)
* Optional text description

*Do NOT store:*

* Precise GPS coordinates
* User location tracking
* Location history

=== Rationale
Manual selection is the only realistic option for the project. It costs nothing, is easy to implement, works everywhere, and is actually more reliable than automatic positioning since students know exactly where they lost/found items.
